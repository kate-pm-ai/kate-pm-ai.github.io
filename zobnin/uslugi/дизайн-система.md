# ZOBNIN TEAM - design system for the services hub

## Principle

The services hub is assembled from the current ZOBNIN TEAM visual language. Existing components are reused without redesign; only the four mobile hero information tiles are new.

## Source components

- Hero, headings, anchor navigation and CTA: `https://zobninteam.ru/individual-training/`.
- Rental block and booking behaviour: `https://zobninteam.ru/arenda-polya-i-zalov/`.
- Service cards and content logic: the current `/services/` page plus Misha's brief.

## Core tokens

- Display/headings: `MartianGrotesk Condensed Bold / Black`.
- Body/UI: `Manrope`.
- Red: `#dd2c2c`; hover `#c82525`.
- Ink: `#121212`.
- Grey surface: `#f2f2f7`.
- White: `#ffffff`.
- Borders: `#e5e5e5`.
- Main container: 1240 px.
- Section padding: 96 px desktop / 68 px mobile.
- CTA: red pill, uppercase, Manrope 800, 54-66 px height.

## Exact typography from the live individual-training landing

- H1: 60 px desktop / 39 px mobile; line-height 1.16; letter-spacing -0.03em; weight 800.
- H2: 48 px desktop / 32 px mobile; line-height 1.16; letter-spacing -0.03em; weight 800.
- H3: 38 px desktop / 27 px mobile; line-height 1.16; letter-spacing -0.03em; weight 800.
- Body: 16 px; hero support text: 18 px desktop / 15 px mobile.
- Small UI: 12-14 px.

## Reuse rules

1. Reuse the current header, phone, primary CTA and form flow.
2. Reuse the live anchor component. On mobile it remains sticky below the header, shows all six links in a 3 x 2 grid and highlights the current section; there is no horizontal scrolling.
3. Keep the source paragraph on desktop. On mobile, replace it with the four information tiles in a 2 x 2 grid while the photo remains a separate media block.
4. Preserve the current card sizes, buttons, section spacing and photo treatment.
5. Preserve the rental widget behaviour from the live rental page.
6. Preserve all approved copy, prices, pending notes and the agreed block order.
7. The prototype is a visual handoff. Production forms and booking actions use the existing Bitrix handlers.

## Standalone prototype

The HTML hotlinks media already used on `zobninteam.ru`. In production, reuse the same Bitrix media entities and components rather than copying image URLs by hand.
